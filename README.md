# APEX-AI @ HiPEAC 2027

Official workshop website for:

**APEX-AI — Approximate, Low-Precision, Sparsity, and Efficient AI Execution from Training to Deployment**

HiPEAC 2027 · Glasgow, UK · 19 January 2027

## Workshop format

APEX-AI is primarily a curated invited-talk workshop, complemented by a small number of contributed presentations selected through an open call for one-page abstract submissions. Abstracts are non-archival and no formal proceedings are planned. No submission is required to attend.

## Website

https://apex-ai-workshop.github.io/hipeac27/

## Editing

Most workshop content is stored in `website-data.js`.

- `index.html` — page structure
- `style.css` — main styling
- `hero-flow.css` — hero/countdown styling
- `website-data.js` — workshop text, dates, topics, speakers, organizers and academic advisors
- `script.js` — dynamic rendering
- `assets/images/apex-ai-logo.png` — APEX-AI logo
- `assets/documents/` — optional folder for the final Call for Participation PDF

## Publishing

Upload these files to the root of the GitHub repository used for:

`https://apex-ai-workshop.github.io/hipeac27/`

Then enable GitHub Pages from the repository's main branch/root.

## Organizer biographies

Organizer profiles follow the RAISE-Arch interaction: biographies are hidden by default, expand inline when a mouse/trackpad passes over a profile, and disappear when the pointer leaves. Keyboard focus also reveals the bio, while touch devices can tap a profile to toggle it.

Chair / Co-Chair / Organizer roles are shown directly on the profile cards.
